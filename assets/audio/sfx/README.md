# SFX Assets

`scripts/systems/audio_manager.gd` will load these files when present:

- `attack_swing.wav`
- `hit_impact.wav`
- `enemy_death.wav`
- `door_unlock.wav`
- `checkpoint.wav`
- `cell_pickup.wav`
- `damage_taken.wav`
- `jump.wav`

If a file is missing, AudioManager falls back to synthesized placeholder tones.
