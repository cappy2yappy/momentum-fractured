## Executed handling

The launcher re-verifies six archives and 1,106 extracted source hashes through ART11/ASSET01's read-only verifier. It compares the supplied runtime manifest to the committed ART11 lineage and verifies all 185 cached frame hashes before launch. No source ZIP or raster is copied into a tracked ENV12 directory. No downloader fetches publisher packs.

Only text/GDScript/Python/HTML/JSON and hash evidence belong in the ENV12 commit. Private captures are composed native room views and remain local under `tools/env12/.private/captures/`; no screenshot pixels, raw packs, derivative art or private-host copy are uploaded to GitHub or other services. [Provenance metadata](provenance.json) and [capture manifest](capture-manifest.json) identify those private outputs without embedding them.

The complete bank is 185 frames / 3,795,784 decoded RGBA bytes; retaining the existing bank avoids rebuilding ART11. This figure includes unused candidates and is not a new optimal production memory budget. Original animation alpha/gutter/loop metrics belong to ART11's earlier evidence. ENV12 freshly verifies bytes and native presentation; it does not claim to have rerun ART11's 580 alpha/animation checks.
