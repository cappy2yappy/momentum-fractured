# Kaze — Silent District Alpha 0.5.0

Windows x86-64 playtest build.

## What changed

- Replaced Wind Tether's one-shot pull with the web prototype's held, momentum-based swing.
- Kept the animated tether visible throughout the swing.
- Added elevated room exits with corresponding elevated entrances.
- Raised encounter density and expanded player/enemy attack overlap to visible body bounds.
- Added Gale Dash afterimages.
- Added throwable Wind, Fire and Electric Kunai (`R`) and element cycling (`T`).
- Added matching persistent elemental seals and saved unlock state.
- Kept the MetSys-backed map, room discovery and persistent progression.

## Scope note

This remains an eight-room proving ground. It is a meaningful parity step, not yet the complete
21-area, five-region, five-boss route from the web demo.

## Run

Extract the Windows ZIP fully, then launch `Kaze.exe`. Godot does not need to be installed.
