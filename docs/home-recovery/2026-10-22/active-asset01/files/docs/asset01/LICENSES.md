## Distribution and placement gates

- Keep original ZIPs, extracted rasters, PSD/AEP files, runtime slices/atlases and asset-only captures outside public Git, PR attachments, CI uploads and standalone downloads. Modification does not remove this restriction. This PR contains text metadata and review tools only.
- No raw-pack mirroring, resale or standalone redistribution. Any future approved game export requires a selected-use packaging review; pilot approval does not approve source-asset publication or release packaging.
- Art Mane reviews selected visual IDs, treatment, scale, pivots and state cues. Level reviews exact room anchors against unchanged collision and safety exclusions. Gameplay owns EN-01/HAZ-01 timing/damage/state interfaces. The creator approves the exact production placements before those are implemented.
- Record approval per asset/derivative and room/anchor; silence, gallery playback and the blanket license attestation are not production-placement approval. No canonical identities or lore follow from pack names.

Optional credit, when used: **Maaot — Mossy Cavern / 2D DarkCave Assets**, linking the actual source page for the selected pack. Keep attribution provenance even when credit is optional.
