# Twelve playable discoveries

## Sequence and delivery
Recommended emotional progression: separation → traces of ordinary life → uncertain routes → cost → room to search → possible loss → possible continuation. The actual graph is nonlinear. B08 can precede B04; B09 can follow B10; B12 can precede B11. No line assumes the player has read another optional object. B11 supplies an unresolved ending even if B12 is never visited.

Critical-path spine: B01 → traversal/combat → B04 → B05 → annex/sigil/region progression → B10 → B11. Only existing progression gates remain required. B02/03/06/07/08/09/12 are optional discoveries. B04/05/10/11 are placed on the main route but their **new** text is optional. There is no “collect all clues” requirement.

## Proposed shared interaction and persistence contract (N; not implemented)
- New examine prompts appear only when grounded on a Level-approved safe standing area, outside combat, hazards, arrival envelopes, pickups, gates and automatic passage triggers. No forced approach, camera lock or movement animation. Offer an input-remappable Examine action; Gameplay must resolve input priority rather than assume E is free.
- Player-facing prose is one short panel or quiet subtitle, manually dismissible; movement/cancel closes it. Never place essential information solely in audio or color. No automatic corpse close-up. Optional VO is not required.
- `st05.bXX.read` are proposed per-save booleans, default false on old saves. Commit only after the line is actually displayed; skip before display, interruption, room exit or death before display leaves false. Re-examination can reread without repeating an automatic reaction. Reading writes no gameplay progression or checkpoint fields. Save migration/namespace ownership requires INT-01 approval.
- New props remain present on revisit. A successful memorial uses its own flag; it never removes the body, clears an objective or grants rewards. No corpse loot, completion percentage or achievement.
- For milestone reactions, queue after the existing mechanic announcement. If room changes or danger resumes, discard the queued line and permit explicit later examination. Never set an existing progression flag to make a narrative line eligible. Existing lore flags must not be repurposed as ST05 read flags.
- New observations are not journal entries unless a journal is separately approved. Without an approved interaction/save adapter, deliver existing-source text and approved opening only; leave new prose and props disabled.
